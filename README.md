# DeerBook

The Hunter's Social Network

## Features
- **Registration & Login** (email + password + display name + camp)
- **Status updates / posts** with real photo upload
- **Stories** (24-hour photo stories with caption)
- **Messenger** (real conversations & messages)
- Official DeerBook logo

## Live Demo
Enable GitHub Pages (Settings → Pages → Deploy from **main** branch → / root).

Then open:

**https://aross197.github.io/deerbook/**

## How to use
1. Open the site
2. Click **Sign Up** and create an account
3. Post updates, upload photos, share Stories, and chat

All data is stored in your browser. Everything is real and persistent for your account.
